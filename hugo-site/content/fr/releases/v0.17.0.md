La version **v0.17.0**, datée du 11 octobre 2026, déplace le dépôt de GitLab vers GitHub et change le chemin du module Go. Elle contient un changement incompatible pour les utilisateurs du module : le chemin du module. Lisez [Mise à niveau](#mise-à-niveau) avant de mettre à jour. Elle ajoute aussi les EIP `Sample` et `SampleEvery`.

## Mise à niveau

Le chemin du module est passé de `gitlab.com/tranchida/gocamel` à `github.com/tranchida/gocamel`. Chaque composant et module d'observabilité a suivi (`github.com/tranchida/gocamel/components/<nom>`, `github.com/tranchida/gocamel/observability/<nom>`).

1. Remplacez l'ancien chemin dans vos imports et dans `go.mod` :

```bash
find . -name '*.go' -o -name go.mod | xargs sed -i 's#gitlab.com/tranchida/gocamel#github.com/tranchida/gocamel#g'
```

2. Mettez à niveau le cœur et chaque module optionnel que vous utilisez, ensemble :

```bash
go get github.com/tranchida/gocamel@v0.17.0
go get github.com/tranchida/gocamel/components/kafka@v0.17.0
```

Chaque module de composant et d'observabilité en v0.17.0 exige le cœur v0.17.0. Les versions jusqu'à v0.16.0 restent disponibles sous l'ancien chemin `gitlab.com/tranchida/gocamel`.

## EIP Sample

`Sample(period)` et `SampleEvery(n)` ne laissent passer qu'un échantillon des échanges et écartent silencieusement les autres avec `ErrStopRouting`, quel que soit leur contenu. `Sample` garde le premier échange de chaque période, `SampleEvery` un échange sur `n` (le premier passe). Contrairement à `Throttle`, qui retarde les échanges, `Sample` les écarte. Une période ou un compteur non positif est signalé par `Route.Validate()`.

## Changements du projet

- Le dépôt est désormais sur [github.com/tranchida/gocamel](https://github.com/tranchida/gocamel) ; les tickets vont sur [GitHub Issues](https://github.com/tranchida/gocamel/issues).
- Le pipeline GitLab CI a disparu. Lancez `./check.sh` en local (build, vet et `go test -race` sur chaque module) et activez le hook pre-push versionné avec `git config core.hooksPath .githooks`.

Consultez le [CHANGELOG](https://github.com/tranchida/gocamel/blob/main/CHANGELOG.md) pour la liste complète.
