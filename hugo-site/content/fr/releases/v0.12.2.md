La version **v0.12.2** est une version corrective pour l’outillage Go 1.27 et la configuration du lint.

- Staticcheck passe à `2026.2.1` et gosec à `v2.29.0`, compatibles avec Go 1.27.
- Le test de régression MongoDB conserve son comportement sans connexion réseau et sans diagnostic de dépréciation.
- Tous les fichiers Go auparavant non formatés sont maintenant formatés avec `gofmt`.

Aucune nouvelle API ni modification de comportement à l’exécution par rapport à v0.12.1.

```bash
go get gitlab.com/tranchida/gocamel@v0.12.2
```
