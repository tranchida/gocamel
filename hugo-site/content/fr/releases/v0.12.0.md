La version **v0.12.0**, datée du 5 septembre 2026, corrige 18 constats concernant le routage, la livraison, la concurrence et le cycle de vie des composants. Elle ajoute 23 tests de régression.

## Mise à jour

Go **1.27.0 ou ultérieur** est requis. Mettez à jour ensemble le cœur et chaque module optionnel utilisé :

```bash
go get gitlab.com/tranchida/gocamel@v0.12.0
go get gitlab.com/tranchida/gocamel/components/kafka@v0.12.0
```

Tous les composants publiés et les modules d’observabilité possèdent des tags `v0.12.0` correspondants et dépendent du cœur corrigé.

## Changements de comportement

- Chaque étape reçoit la sortie de la précédente, y compris ses en-têtes, puis `Out` est réinitialisé. Utilisez `GetResponse()` pour lire le message terminé.
- `PollEnrich` prend en charge `seda`, `chan` et les implémentations personnalisées de `PollingEndpoint`. Il préserve les autres messages de la file et refuse les endpoints incompatibles avant toute consommation. Un timeout nul est non bloquant.
- Kafka réessaie un message en échec avant d’en lire un autre. Un commit en échec est réessayé sans refaire le traitement réussi. Configurez la gestion des erreurs de route pour résoudre les échecs permanents, qui bloquent sinon ce consommateur jusqu’à son arrêt.
- Split, Multicast et RecipientList parallèles agrègent dans l’ordre d’entrée après la fin des workers. Chaque branche traitée termine ses callbacks ; les panics d’agrégation deviennent `ErrProcessorPanic`. Les éléments mutables pris en charge sont copiés avant les workers du Split.

## Autres corrections

Les consultations d’état ne bloquent plus le démarrage ou l’arrêt, et le cache d’historique des messages est synchronisé. MongoDB conserve `_id` lors d’un échec de sauvegarde ; FTP sérialise les transferts sur une connexion partagée ; IMAP IDLE réagit aux notifications ; Cron attend les jobs actifs à l’arrêt ou en pause. TCP respecte l’annulation et les délais d’écriture. Les routes Redis peuvent redémarrer et les clients partagés restent disponibles pour leurs utilisateurs actifs. File préserve l’intention de répertoire du slash terminal. Resequence signale les expressions invalides à la construction ; Prometheus réutilise les collecteurs compatibles lors d’enregistrements répétés.

Consultez les [concepts](../../concepts/), les [contrats des EIP](../../eip/) et les [détails des composants](../../components/) pour les comportements actualisés.
