La version **v0.14.2**, datée du 3 octobre 2026, corrige les tags des modules des v0.14.0 et v0.14.1. Le code du cœur est identique à celui de la v0.14.0 : lisez les [notes de version v0.14.0](../v0.14.0/) pour les changements et les notes de mise à niveau.

## Mise à niveau

Mettez à niveau le cœur et chaque module optionnel que vous utilisez, ensemble :

```bash
go get gitlab.com/tranchida/gocamel@v0.14.2
go get gitlab.com/tranchida/gocamel/components/kafka@v0.14.2
```

Tous les composants publiés et les modules d'observabilité ont des tags `v0.14.2` correspondants et requièrent le cœur `v0.14.0` ou ultérieur.

## Corrections

- **Tags des modules** : les tags `v0.14.0` et `v0.14.1` des modules `components/*` et `observability/*` ont été créés avant le commit de release, donc leur `go.mod` requérait encore le cœur v0.13.1. Sans dépendance directe sur le cœur v0.14.0 ou ultérieur, les composants Kafka, STOMP et gRPC ne compilaient pas (`undefined: gocamel.ConsumerRedeliveryPolicy`, `IsCamelHeader`...). Les modules v0.14.2 requièrent le cœur v0.14.0, et leur `go.sum` contient ses checksums publiés.
- Les modules Kafka, STOMP et gRPC rétractent les v0.14.0 et v0.14.1 : `go get` les ignore et `go list -m -u` les signale.

## Validation

Chaque module de composant, d'observabilité et d'exemples compile hors du workspace (`GOWORK=off`) avec le cœur v0.14.0 publié.
