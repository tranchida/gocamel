Version **v0.14.2**, dated October 3, 2026, fixes the module tags of v0.14.0 and v0.14.1. The core code is the same as v0.14.0: read the [v0.14.0 release notes](../v0.14.0/) for the changes and the upgrade notes.

## Upgrade

Upgrade the core and each optional module you use together:

```bash
go get gitlab.com/tranchida/gocamel@v0.14.2
go get gitlab.com/tranchida/gocamel/components/kafka@v0.14.2
```

All published components and observability modules have matching `v0.14.2` tags and require the core `v0.14.0` or later.

## Fixed

- **Module tags**: the `components/*` and `observability/*` tags `v0.14.0` and `v0.14.1` were created before the release commit, so their `go.mod` still required core v0.13.1. Without a direct requirement on core v0.14.0 or later, the Kafka, STOMP and gRPC components failed to build (`undefined: gocamel.ConsumerRedeliveryPolicy`, `IsCamelHeader`...). The v0.14.2 modules require core v0.14.0, and their `go.sum` holds its published checksums.
- The Kafka, STOMP and gRPC modules retract v0.14.0 and v0.14.1, so `go get` skips them and `go list -m -u` warns about them.

## Validation

Every component, observability and examples module builds outside the workspace (`GOWORK=off`) against the published core v0.14.0.
