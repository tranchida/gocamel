Version **v0.17.0**, dated October 11, 2026, moves the repository from GitLab to GitHub and changes the Go module path. It contains one breaking change for importers: the module path. Read [Upgrade](#upgrade) before upgrading. It also adds the `Sample` and `SampleEvery` EIPs.

## Upgrade

The module path changed from `gitlab.com/tranchida/gocamel` to `github.com/tranchida/gocamel`. Every component and observability module moved with it (`github.com/tranchida/gocamel/components/<name>`, `github.com/tranchida/gocamel/observability/<name>`).

1. Replace the old path in your imports and in `go.mod`:

```bash
find . -name '*.go' -o -name go.mod | xargs sed -i 's#gitlab.com/tranchida/gocamel#github.com/tranchida/gocamel#g'
```

2. Upgrade the core and each optional module you use together:

```bash
go get github.com/tranchida/gocamel@v0.17.0
go get github.com/tranchida/gocamel/components/kafka@v0.17.0
```

Every component and observability module at v0.17.0 requires core v0.17.0. Releases up to v0.16.0 stay available under the old `gitlab.com/tranchida/gocamel` path.

## Sample EIP

`Sample(period)` and `SampleEvery(n)` let only a sample of the exchanges through and silently drop the others with `ErrStopRouting`, regardless of their content. `Sample` keeps the first exchange of each period, `SampleEvery` one exchange out of `n` (the first one passes). Unlike `Throttle`, which delays exchanges, `Sample` discards them. A non-positive period or count is reported by `Route.Validate()`.

## Project changes

- The repository now lives at [github.com/tranchida/gocamel](https://github.com/tranchida/gocamel); issues go to [GitHub Issues](https://github.com/tranchida/gocamel/issues).
- The GitLab CI pipeline is gone. Run `./check.sh` locally (build, vet and `go test -race` on every module) and enable the versioned pre-push hook with `git config core.hooksPath .githooks`.
