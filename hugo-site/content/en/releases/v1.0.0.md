Version **v1.0.0**, dated November 23, 2026, is the first stable release of GoCamel. It follows a comprehensive security, concurrency, and correctness audit covering the core routing engine, Simple Language, JSONPath, DataFormats, observability modules, and all 17 optional components, alongside Ollama Cloud support and dependency security upgrades. Every component and observability module at v1.0.0 requires core v1.0.0.

## Highlights

- **Ollama Cloud support**: when `OLLAMA_API_KEY` is set, the `ollama` producer authenticates with a Bearer token against `ollama.com` and its subdomains over HTTPS only, leaving local and LAN hosts untouched.
- **Dependency security upgrades**: upgraded `google.golang.org/grpc` (`v1.85.0`), `golang.org/x/crypto` (`v0.59.0`), `github.com/pkg/sftp` (`v1.13.12`), `go.opentelemetry.io/otel` (`v1.47.0`), and `github.com/nats-io/nats-server/v2` (`v2.15.3`, `nats.go` `v1.55.0`).
- **Recursive-descent Simple Language & bounded JSONPath**: replaced the Simple Language evaluation cascade with a recursive-descent parser, exact numeric comparisons, `int64` `file:length`/`file:size`, UTF-8 rune-aware string functions (`substring`, `capitalize`, `padstart`, `padend`), and quote-aware `${...}` parsing. Hardened JSONPath with quote-aware brackets, negative slices, `$..[...]`/`$..*`, and cycle/depth/result/visit bounds.
- **Security hardening across core and components**: unified 18 sensitive URI keys in `RedactURI`, per-URI `EvaluateURI` escaping against dynamic endpoint injection and SSRF (`RecipientList`, `RoutingSlip`, `DynamicRouter`, `PollEnrich`), 4-dialect lexical SQL validation, `file` symlink TOCTOU (`O_NOFOLLOW`) and OOM protection, FTP CR/LF command injection blocking, STOMP reserved-header and `\x00` framing protection, ZipCrypto CRC and WinZip AES pre-decrypt MAC verification, and redirect/response-size hardening across HTTP and AI components.

## Behaviour changes

- **`sql-stored` parameters**: unordered `map[string]any` bodies are rejected (pass an ordered `[]gocamel.StoredProcedureParam`), and `ParamDirectionOut` / `ParamDirectionInOut` parameters return an error rather than binding silently as plain `IN` values.
- **`sql` & `sql-stored` options**: SQL endpoint options (`query`, `procedure`, `dataSourceRef`, `outputType`, `batch`, `transacted`, `noop`, `allowHeaderOverride`) are read strictly from URI query parameters, ignoring environment variables.
- **Empty-result `In.Body` clearing (`sql`, `mongodb`, `redis`)**: zero-row `sql` `SelectOne`, `mongodb` `findOne` on `mongo.ErrNoDocuments` (setting `CamelMongoDbResultTotal=0`), and `redis` `GET` on `redis.Nil` clear both `In.Body` and `Out.Body` to `nil`.
- **`grpc` consumer TLS & status**: `GRPCConsumer` enforces TLS 1.2+ and rejects `insecure=false` unless both `certFile` and `keyFile` are set; it reads `exchange.GetResponse()`, requires `CamelGrpcStatusCode > 0` for errors, and sanitizes internal error details. `GRPCProducer` enforces `timeout` and filters `Camel*` headers.
- **`direct` lifecycle**: `DirectProducer.Send` requires the target `DirectConsumer` to be started (`Start()`).
- **`http` redirects & gzip**: `NewHTTPComponent` blocks HTTPS→HTTP downgrades and strips sensitive headers on cross-origin redirects by default (customizable via `SetCheckRedirect`); the producer drops outbound `Accept-Encoding` so `http.Transport` handles gzip transparently.
- **Archive unmarshaling (`zip`, `tar.gz`)**: entry names starting with `/` or `\` are rejected instead of having leading slashes stripped.
- **`template` encoding & confinement**: non-UTF-8 `encoding` values fail fast at endpoint creation, and `CamelTemplatePath` overrides are confined to the endpoint template directory.
- **AI components (`anthropic`, `openai`, `ollama`, `jev`)**: reject `nil` bodies and hostless/opaque `baseURL` values, refuse 3xx redirects, and bound responses to 32 MiB. `anthropic` disables SDK env auto-loading (`WithoutEnvironmentDefaults()`), reads `ANTHROPIC_API_KEY`, and validates/applies `temperature` in `[0, 1]`; `openai` reads `OPENAI_API_KEY`.
- **`mail` polling & fetch**: `DefaultPollDelay` is fixed from `60µs` to `60s`, `maxMessageSize` defaults to 32 MiB when `<= 0`, IMAP uses `BODY.PEEK[]` and `UIDExpunge`, POP3 uses `RetrRaw`/MIME with `LIST` size limits and `QUIT` after `DELE`, and SMTP validates addresses with `net/mail`.
- **`file` directory writes**: `CamelFileName` is required when the producer URI points to a directory.
- **Bounded in-memory repositories**: `MemoryIdempotentRepository` (`100_000`) and `MemoryClaimCheckRepository` (`10_000`, UUID keys) are bounded by default.
- **`cron`**: `trigger.repeatCount=0` returns immediately without scheduling; `deleteJob=false` retains the entry on `Stop()`; unspaced `TZ=`/`CRON_TZ=` prefixes are rejected.

## Upgrading

- Replace `map[string]any` payloads sent to `sql-stored` with ordered `[]gocamel.StoredProcedureParam` slices, and move any SQL options previously supplied via environment variables into the endpoint URI.
- Provide `certFile` and `keyFile` on `GRPCConsumer` endpoints using `insecure=false` (or explicitly set `insecure=true` for plaintext local testing).
- If an `anthropic` route relied on SDK ambient variables (`ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`), pass them explicitly via URI options or `ANTHROPIC_API_KEY`.
- Ensure `DirectConsumer` routes are started before calling `DirectProducer.Send`, and set `CamelFileName` when writing to a `file:` directory endpoint.
- Check downstream processors handling empty results from `sql` (`SelectOne`), `mongodb` (`findOne`), or `redis` (`GET`): `In.Body` is now `nil` instead of retaining the input query/filter/key.
