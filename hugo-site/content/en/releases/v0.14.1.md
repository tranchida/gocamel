Version **v0.14.1**, dated October 3, 2026, fixes the module tags of v0.14.0. The core code is the same as v0.14.0: read the [v0.14.0 release notes](../v0.14.0/) for the changes and the upgrade notes.

## Upgrade

Upgrade the core and each optional module you use together:

```bash
go get gitlab.com/tranchida/gocamel@v0.14.1
go get gitlab.com/tranchida/gocamel/components/kafka@v0.14.1
```

All published components and observability modules have matching `v0.14.1` tags and require the core `v0.14.0` or later.

## Fixed

- **Module tags**: the `components/*/v0.14.0` and `observability/*/v0.14.0` tags were created before the release commit, so their `go.mod` still required core v0.13.1. Without a direct requirement on core v0.14.0, the Kafka, STOMP and gRPC components failed to build (`undefined: gocamel.ConsumerRedeliveryPolicy`, `IsCamelHeader`...). The v0.14.1 modules require core v0.14.0, and their `go.sum` holds its published checksums.

## Validation

Every component, observability and examples module builds outside the workspace (`GOWORK=off`) against the published core v0.14.0.
